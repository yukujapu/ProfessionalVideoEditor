# Professional Video Editor

iPhone Safari向け動画編集Webアプリの初期プロトタイプです。

## ファイル
- `index.html` : 画面構造
- `style.css` : デザイン
- `script.js` : 画面切替、プロジェクト一覧、素材リストなど

## 起動
ReplitでHTML/CSS/JSのWebプロジェクトにファイルを配置し、RunまたはPreviewで起動してください。

## 注意
これは開発の土台となる初期版です。実際の動画編集、音声波形、キーフレーム、エフェクト処理、動画書き出しはまだ実装されていません。プロジェクト情報はブラウザのlocalStorageに保存されます。素材ファイル本体はまだ永続保存されません。
